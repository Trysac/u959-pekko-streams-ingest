# Stack

- **Language**: Scala 3.9.0 on JVM 21 (`--release 21`, `-no-indent`, `-Werror`).
- **Streaming Engine**: Apache Pekko Streams 2.0.0 (`org.apache.pekko:pekko-stream_3`).
- **Testing**: MUnit 1.3.6, MUnit-ScalaCheck 1.3.1, and Apache Pekko Stream TestKit 2.0.0 (`org.apache.pekko:pekko-stream-testkit_3`).
